## 使用说明

1. **运行时自动创建**：场景启动时会自动创建Studio UI界面
2. **编辑器工具**：可以使用 `Tools > Studio UI > 创建Studio界面` 手动创建
3. **所有按钮可点击**：点击任何按钮都会在Console输出日志
4. **状态栏显示**：所有操作都会更新状态栏信息
